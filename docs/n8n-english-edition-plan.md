# 英文版週刊文計畫（延後執行）

目的：在維持 AdSense 重審安全邊際的前提下，讓英文讀者也持續有新內容可看。核心原則：英文版不是機翻，是獨立在地化改寫；量體與中文版 1:1（每週一篇），不做回填舊文的批次翻譯。

## 背景

2026-07-25 盤點時發現，舊系統的英文文章與中文文章一樣是套版量產（多數為逐句機翻或另一支模板化 LLM 呼叫），且站上完全沒有 `hreflang` 標籤讓 Google 知道中英版本是同一內容的語言對應——這兩點疊加是英文版被歸類為低價值內容的主因，**不是「有英文版」本身的問題**。詳見 `memory/2026-07-25-adsense-weekly-blog-system.md`（tu-vault）。

`hreflang` 缺口已於 2026-07-25 順手補上（`app/lib/blog.ts` 新增 `getAlternateLanguageSlug`，`app/[locale]/blog/[slug]/page.tsx` 的 `generateMetadata` 加上 `alternates.languages`），不需要等這個計畫執行才能生效。

## 為什麼延後

中文週刊系統（紫微策展週刊 1.0）剛上線，若同時把英文自動化也接上去，一旦下次 AdSense 審核結果不理想，無法判斷是哪個變因造成的。先讓中文單獨跑穩、送審，通過後再加英文，變數乾淨、好歸因。

## 時程

| 階段 | 時間 | 內容 |
|---|---|---|
| Phase 0（已完成） | 2026-07-25 | hreflang 標籤上線；本次過渡先由人工／Claude 手動產出當週英文版（見下方「近期內容過渡方案」），不等自動化 |
| Phase 1 | 2026-07-26 – 約 2026-08-23（4 個週一） | 中文週刊獨立跑滿 4 週，每週人工抽查品質閘門是否正常通過、文章是否確實刊出 |
| Phase 2 | 約 2026-08-23 之後 | 重新送出 AdSense 審核 |
| Phase 3 | **AdSense 審核有結果之後**（通過或有明確拒絕原因排除是內容量問題後）才執行 | 在 n8n 「紫微策展週刊 1.0」加入英文在地化改寫節點 + 英文版品質閘門，開始自動雙語週刊 |

Phase 3 沒有寫死日期，因為它的觸發條件是「審核結果出爐」而非單純時間到——若 2026-08-23 審核還沒送出或還沒有結果，Phase 3 順延。

## Phase 3 要做的事（屆時展開實作）

1. n8n 新增一個 LLM 節點，緊接在中文「王老師寫作」品質閘門通過之後：
   - 輸入：已通過品質閘門的中文全文、`selected_sources`、知識庫條目
   - 任務：**在地化改寫，不是逐句翻譯**——對非台灣讀者需要的背景（例如台灣地方政治人物是誰、事件脈絡）要補充一兩句說明，不能假設讀者有本地新聞背景；理論引用、參考資料、免責聲明結構比照中文版
   - 輸出：`{title, content, tags, slug}`（英文）
2. 英文版獨立的品質閘門（不能沿用中文字數門檻，中英文資訊密度不同）：
   - 字數改用英文字數（非字元數），建議下限 900–1,200 words
   - 其餘規則（參考資料區塊、連結數 ≥2、免責聲明、標題與近期英文標題重合度 <60%）比照中文版邏輯，但比對對象改成近期**英文**標題
3. 發布時機：中文版發布後間隔至少數小時到一天再發布英文版（避免同時間戳造成的重複內容訊號），`translated_from` 設為中文版 id，`author` 沿用「王老師」
4. 前台：確認新文章的 hreflang alternate 正確產生（沿用已上線的機制，理論上不需要改動）

## 執行前要驗證的事項（Phase 3 啟動前的 checklist）

- [ ] AdSense 重審已有明確結果（通過，或拒絕原因已排除「內容量/雷同內容」相關項目）
- [ ] 中文週刊過去 4 週每週都成功發布、品質閘門記錄無異常（去 n8n 執行紀錄核對）
- [ ] 英文品質閘門的字數門檻已根據英文寫作節點實際輸出長度校準過（不是直接沿用中文的 1800 字元）
- [ ] 在地化改寫節點至少手動測試 1 次，人工檢查輸出是否為「改寫」而非「翻譯腔」逐句對照
- [ ] hreflang 標籤在測試文章上跑過 curl / Google Rich Results Test 驗證雙向連結正確
- [ ] 確認 `translated_from` 外鍵、`author`、`slug` 唯一性等既有規則對英文文章仍然正確套用
- [ ] 新節點可以獨立停用（不影響中文週刊主流程），保留回退能力

## 近期內容過渡方案（不等 Phase 3）

在 Phase 3 開始前，若中文週刊持續每週產出新文章，英文版由 Claude 人工在地化改寫、你審過再發布，一週最多一篇，維持跟中文 1:1、不批次回填。第一篇示範已於 2026-07-26 手動產出（盧秀燕總統運政治命理文的英文在地化版本），流程與 Phase 3 描述的品質標準相同，只是由人工執行而非 n8n 節點。
