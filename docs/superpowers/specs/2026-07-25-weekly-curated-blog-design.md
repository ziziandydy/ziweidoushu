# 每週自動策展觀點文系統 — 設計文件

日期：2026-07-25
狀態：已與站長確認設計，進入實作規劃

## 背景與目標

AdSense 申請未通過，主因判定為「低價值內容」：現行 n8n 每日自動發文產出 330+ 篇模板化文章（標題高度重複、無作者署名、無引用來源），且英文版為未經審校的機器翻譯。

本設計以「每週一篇有深度、有引用、有署名的策展觀點文」取代每日量產，並補齊 E-E-A-T 信號，目標是通過 AdSense 重審。

## 1. n8n Workflow（每週一早上觸發）

1. **蒐集**：Google News RSS ＋ 固定關鍵字組（紫微斗數、運勢、命理 × 財運/感情/職場/健康），取近 7 天文章的標題、連結、摘要；過濾重複站點，留 10–15 篇候選。
2. **選題**：LLM 從候選挑一個值得評論的主題角度；同時呼叫 `/api/blog/list` 取最近 10 篇已發文標題，強制新主題不得與其重複。
3. **知識庫檢索**：呼叫 `/api/knowledge?tags=…` 取回該主題相關經典論述條目。
4. **寫作**：高階模型（Claude Sonnet 等級；不用 gpt-4o-mini）生成 1,800–2,500 字。Prompt 硬性要求：
   - 文末「參考資料」清單，外部來源附連結
   - 引用知識庫論述時標明書名出處
   - 固定作者署名
   - 免責聲明（僅供娛樂與文化學習參考）
5. **品質閘門**：字數下限 1,800、參考來源 ≥2、與最近 10 篇標題相似度檢查、敏感詞檢查。未通過重生成一次；再未通過則通知站長、該週不發。
6. **發布**：POST 現有 blog API（published）。
7. **通知**：email 摘要（標題＋連結＋引用來源清單）給站長抽查。

任一節點失敗：通知站長，該週跳過不發文。

## 2. 知識庫（repo 內）

- 位置：`content/knowledge/*.md`，每檔一個主題（十二宮位、十四主星、四化、常見格局）。
- Frontmatter：`topic`、`tags`、`source`（出處書名）。
- API：新增 `/api/knowledge?tags=…`，以 tag/關鍵字比對回傳條目。不做向量檢索（YAGNI）。
- 初版：按中州派理論架構起草 20–30 條，站長校對後上線；後續在 git 增修。

## 3. E-E-A-T 配套（repo 內）

- 文章資料結構加 `author` 欄位；文章頁顯示署名＋簡介。
- 新增「關於本站」頁，內容：
  1. 本站是什麼（中州派紫微斗數 × AI 分析工具）
  2. 方法論（理論根據、知識庫經典書目、AI 分析運作方式）
  3. 內容透明度聲明（AI 輔助撰寫、站方監督、附引用、僅供娛樂與文化學習參考）
  4. 作者署名：預設「AI 紫微編輯室」＋簡介；站長可換成真名/筆名（建議，可信度較高）。不虛構人設。
  5. 聯絡方式：沿用隱私政策的 email 與支援表單
- 關閉現行每日 n8n workflow。
- 新文章暫停自動翻英文（batch-translate 停用），中文線穩定後再評估。
- 既有高重複舊文的 noindex/下架另開任務處理，不在本 spec 範圍。

## 4. 版權界線

外部來源只取「標題＋摘要＋連結」進 prompt；不餵全文、不改寫轉載。產出為原創評論，文末附來源連結。

## 5. 分工

- repo 內（本專案實作）：知識庫內容與檔案結構、`/api/knowledge`、author 欄位、文章頁署名顯示、「關於本站」頁。
- n8n：產出節點級設定文件供站長照建（或後續以瀏覽器自動化協助設定）。

## 驗收標準

1. `/api/knowledge?tags=財帛宮` 回傳含出處的條目 JSON。
2. 新發文章帶 author 欄位並顯示於文章頁。
3. 「關於本站」頁上線且被首頁/footer 連結。
4. n8n 設定文件完整到可照步驟建出 workflow（含每步的 prompt 與品質閘門規則）。
5. 現行每日發文 workflow 已關閉。
